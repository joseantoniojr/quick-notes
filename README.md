# Quick Notes

Aplicação web para criação e gerenciamento de notas de forma simples e rápida.

🔗 **[Acessar o projeto](https://joseantoniojr.github.io/quick-notes/)**

## Sobre o projeto

O **Quick Notes** foi desenvolvido como projeto de portfólio para praticar fundamentos de desenvolvimento web com JavaScript, organização de código e construção de uma interface responsiva.

A aplicação permite criar, editar, excluir e favoritar notas, além de filtrar as notas favoritas e alternar entre os temas claro e escuro.

## Funcionalidades

- Criar novas notas
- Editar notas existentes
- Excluir notas com confirmação
- Favoritar e desfavoritar notas
- Filtrar notas favoritas
- Persistir notas no `localStorage`
- Persistir a preferência de tema
- Alternar entre tema claro e escuro
- Estado vazio quando não existem notas
- Interface responsiva
- Organização das notas em cards
